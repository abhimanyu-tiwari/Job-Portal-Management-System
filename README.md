# 💼 Job Portal Management System

A modern and scalable **Job Portal Management System** built using **React.js, Spring Boot, Spring Security, JWT, Hibernate, and MySQL**. The application connects job seekers and recruiters through a secure platform where candidates can apply for jobs, recruiters can post vacancies, and administrators can manage the entire system.

---

## 🚀 Project Overview

The Job Portal Management System is a full-stack web application designed to simplify the recruitment process. It provides separate dashboards for **Candidates**, **Recruiters**, and **Administrators**, with secure authentication, role-based authorization, and an intuitive user interface.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/abhimanyu-tiwari/Job-Portal-Management-System.git
```

### Navigate to Project

```bash
cd Job-Portal-Management-System
```

### Backend Setup

```bash
cd backend
mvn clean install
mvn spring-boot:run
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
